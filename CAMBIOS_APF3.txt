OBJETIVO
--------
Validar correctamente la carga de archivos CSV/JSON en el módulo de
administración y soportar las pruebas de integración del entregable APF3.


--------------------------------------------------------------------------------
1. VALIDACIÓN DE CARGA CSV/JSON
--------------------------------------------------------------------------------

Archivo nuevo:
  src/utils/upload_validation.py

Funciones:
  - validate_csv_bytes(content) -> (validos, invalidos)
  - validate_json_bytes(content) -> (validos, invalidos)

Campos requeridos (alineados con el frontend):
  - id_cuadrante
  - id_tipo_delito
  - fecha_delito
  - ubicacion

Validaciones:
  - CSV: cabecera obligatoria, columnas requeridas, al menos 1 fila de datos
  - JSON: arreglo no vacío, cada objeto con los 4 campos
  - Filas/registros incompletos se cuentan como inválidos
  - Normalización de nombres de columnas (minúsculas, sin BOM utf-8-sig)


--------------------------------------------------------------------------------
2. ENDPOINT ADMIN - upload-csv (MODIFICADO)
--------------------------------------------------------------------------------

Archivo: src/api/routes/admin.py

Cambios:
  - Lee el archivo completo en memoria antes de guardar
  - Rechaza archivo vacío (HTTP 400)
  - Valida esquema con upload_validation antes de escribir en disco
  - ELIMINADO fallback que inventaba 15420 registros si fallaba la lectura
  - Respuesta incluye:
      * registros  -> cantidad de filas válidas
      * invalidos  -> cantidad de filas inválidas omitidas
      * message    -> texto de éxito
  - Estado en BD (lotes_importacion):
      * valid / invalid reales
      * state: "completado" o "con_advertencias" si hay inválidos
  - Errores de formato devuelven HTTP 400 con mensaje claro en detail

Ejemplo error 400:
  "Formato CSV inválido. Faltan columnas: fecha_delito, ubicacion."
